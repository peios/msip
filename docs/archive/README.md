# MSIP specification archive

`pre-bazel/msip-specification` preserves the original component-owned PGSS
chapter from Learn staging before its rewrite. `source-map.json` records each
original relative path and SHA-256 identity. The maintained protocol chapter
and integration guide live under `docs/learn`.

The original presentation-hints guide remains in Learn staging because it
specifies installer-owned renderers and tools, rather than this Rust library.
This archive is repository history and is not merged into Peios Learn.
